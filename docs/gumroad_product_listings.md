1. Go to **gumroad.com** → Sign up (free, no monthly fee — they take 10% per sale)
2. Click "New Product" for each listing below
3. Copy-paste the title, description, and set the price
4. Upload a ZIP containing your source code + README
5. Add a cover image (screenshot of the app)

## Before You List: Preparation Checklist

- [ ] **Remove all client-specific data** (business names, logos, real customer data)
- [ ] **Remove API keys** from code (use .env.example instead)
- [ ] **Add a clear README.md** with: setup steps, required env vars, deployment guide
- [ ] **Add .env.example** listing every required variable
- [ ] **Add a seed script** so buyers can see the app with sample data
- [ ] **Test a fresh clone** — can someone else run `npm install && npm run dev`?
- [ ] **Add a LICENSE file** (commercial license: "Use in unlimited personal/client projects. No resale of the template itself.")
- [ ] **Take 3-4 screenshots** for the Gumroad listing
- [ ] **Create a cover image** (1280x720, show the dashboard/main screen)
